# 滑模观测器

本页保留参数、调试命令与历史实测记录。完整算法推导及有感/HFI/SMO 的关系见 [FOC 算法文档](foc-algorithms.md)，定点计算与执行时序见 [实现文档](foc-implementation.md)。其中低速阶段应理解为 HFI 初始化和观测辅助的旋转场启动，SMO 接管后才使用观测角与速度反馈闭环。

`firmware/Control/Src/smo.c` 使用 αβ 电压、电流估计反电动势、电角度和电速度。低速电流模型采用后向 Euler，200 us 快 SMO 使用梯形积分，保存两轴上一帧的电压减滑模校正值，降低大负 Id 下的离散相位误差。校正、滤波和 PLL 使用定点整数。`Smo_Prepare()` 预计算模型系数，电流模型更新使用 32 位乘法和移位。电压增益采用 Q8。

普通控制模式按 1 ms 更新。低速 HFI 辅助场按 1.6 ms 解调帧更新，d/q 电流 PI 使用 8 个 200 us 时间刻度。SMO 完成交接、参考速度达到 40 rad/s 且估速达到 30 rad/s 后，切入独立的 200 us SMO／电流环，PWM 与 ADC 改为 20 kHz，每四次转换发布一个均值。启动正 Id 在交接完成后按 625 mA/s 退出，两种采样率下均保持该时间斜率。低于 100 rad/s 的启动先退完正 Id 再进入快环，参考速度达到 100 rad/s 时允许提前切入，避免启动路径采样率限制高速加速。SMO 估速降至 20 rad/s 时恢复 1.6 ms 路径，随后继续按反电动势判据决定是否回到 HFI。

两种无感采样率下，速度 PI 的积分周期都为 8 ms，Iq 斜坡均约为 2.5 A/s。切换采样率时按比例换算观测器速度、重算电流模型系数，并保持控制角度和归一化 PWM 电压衔接。SMO 采用离散一阶滤波器的精确相位补偿。诊断与 RTT 队列均为 500 Hz，快 SMO 下编码器诊断每 2 ms 读取一次，1000 rad/s 时两次读取的机械角增量约为 2 rad，保持在半圈内。编码器诊断独立于无感控制反馈。

采样率切换后的 40 ms 内，反电动势仍可见且 PLL 误差小于 15° 时，将小于 120° 的采样平均／滤波延迟变化吸收到相位偏置中，再按每帧最多 16 个电角度计数消除偏置，保持输出角连续。稳定运行时的相同修正限定在 45° 内。大角度异常仍按丢锁规则处理。

无感命令范围为 ±1000 rad/s。参考轨迹默认加减速度为 100 rad/s²，`hfi-ramp 200` 在运行中将斜率改为 200 rad/s²，可设置范围 5～1000 rad/s²。斜率保存在 RAM，停机后保留，复位恢复默认值。625 Hz 启动阶段参考速度限制为 ±100 rad/s，完成观测交接并进入 5 kHz 路径后继续加速至目标，避免低速路径相位混叠。定点速度换算采用 Q16 系数和拆分乘积，比例误差小于 0.9 ppm，覆盖整个命令范围。加速度除以 5000 使用有界倒数和精确商修正，小数部分跨帧累计以保持两种采样率下一致。

## 2026-11-06 反转与高速修正

此前运行中的方向判据直接比较目标速度符号与 SMO 方向，反转命令会在转子仍正转时启动回退计时。当前运行跟踪按实际反电动势和相位连续性判断，目标速度通过参考轨迹和速度 PI 完成制动，低速再续接 HFI。

此前 SMO 的单次电角增量限幅为四分之一周，在 1.6 ms、七极对下对应约 140 rad/s。该采样率在 300 rad/s 时每电周只有约 1.87 个采样，带符号相位差已发生混叠。当前增量限幅改为小于半周，并在中高速切入 5 kHz 路径，300 rad/s 时每电周约有 15 个采样。

Debug 和 Release 构建及离线回归已通过。构建占用见 `verify` 的构建日志，实机结果见本页后续记录。

## 反电动势判据

`Smo_IsValid()` 要求滤波幅值达到 `min_emf_mv`、PLL 平均绝对误差小于 15°，并连续满足 32 个更新。`Smo_CanTakeOver()` 进一步检查幅值迟滞和持续时间。

| 参数 | 当前初值 |
| --- | --- |
| 最小可观测幅值 | 120 mV |
| 切入幅值 | 400 mV |
| 切回幅值 | 280 mV |
| 切入持续时间 | 100 ms |

HFI→SMO 交接要求转速估计一致，滤波后的场角偏差不超过 ±22.5°，瞬时偏差小于 45°。角差按电角度回绕计算，并以每帧 1/8 的权重滤波，避免门槛附近的采样抖动持续清零资格计时。条件持续满足 100 ms 后，用实际角度偏置开始交接，每帧向零减少最多 16 个电角度计数，载波幅值随混合系数逐步减至零。速度 PI 从交接阶段开始工作，以当前 q 轴参考初始化积分器。HFI 励磁不转换为 q 轴转矩。

无感速度环使用独立 PI，默认 Kp 为 0.005、Ki 为 0.020，主机命令为 `gain sensorless-speed 0.005 0.020`。角度混合完成后，d 轴启动电流每累计 1.6 ms 减少 1 mA，从默认 400 mA 退出约需 0.64 秒。电流 Park 变换使用已完成解调帧的控制角，逆 Park 使用新输出角。编码器诊断测速按两次读取的实际微秒间隔计算，trace 取点时刷新编码器；诊断数据不参与无感控制。

SMO 运行时按反电动势、PLL 和实际相位连续性判断跟踪状态。指令速度与实际速度之间的差值用于速度 PI，改变目标的符号会先让参考轨迹减速。反电动势连续低于 280 mV 达 40 ms 且最近可信估速处于约 ±20 rad/s 内时，恢复低速 HFI。回退以最近实际控制角和速度续接，参考轨迹随后平滑过零反转。500 ms 后允许重新交接。低速估角突跳可提前启动同样的回退。

高速下单次估角突跳使用最近可信速度续接相位。持续失锁达 40 ms 会关闭驱动并上报 `SMO signal lost`，以避免在高速下启动失同步的 HFI 旋转场。默认切入值 400 mV、切回值 280 mV 来自此前低速无感交接实测。约 250 mV 时旁路观测有效，但直接接管会失锁，因此低速继续保持 HFI。

电压达到限幅时，速度 PI 暂停沿饱和方向积累积分，反向制动仍允许退积分。12 V 母线下线性 SVPWM 的电压矢量上限为 `12000 / sqrt(3)`，取 6928 mV，作为默认值和运行时最大值。`limits 2000 6928` 将电流矢量上限设为 2 A 并使用完整线性调制范围。电流 PI 按 `Vq_max = sqrt(Vmax² − Vd²)` 限幅，HFI 期间还预留剩余注入电压，代替此前 `|Vd| + |Vq|` 的保守限制。SMO 默认滑模增益增至 9000 mV，覆盖扩大的工作电压。

反电动势是电机旋转时产生的电压，工程中使用的幅值参数为 19 mV/(rad/s)。按该参数估算，300 rad/s 对应约 5.7 V，电流建立还需要电阻压降和电感电压。5 V 输出上限会限制可达速度，使用完整母线调制范围可增加裕量。忽略压降时，6.928 V 对应约 365 rad/s，实际电机参数、负载与损耗会改变这个值。更高速度使用下述电压裕量弱磁控制。±1000 rad/s 定义命令和数值运算范围。

## 电压裕量弱磁

快 SMO 完成交接、估速绝对值达到 200 rad/s 时，125 Hz 电压环按已输出 d/q 电压幅值与配置的利用率目标调整负 Id。积分状态采用 Q6 mA，64 mV 电压超额在一次 8 ms 更新中增加 1 mA 负 Id。目标另受配置的变化率和最大负 Id 限制，实际 d 轴参考每个快环更新向负方向最多变化 1 mA、向正方向最多变化 4 mA。低速、退出 SMO 或关闭弱磁时释放负 Id。

```text
fw-config 1000 950 1000
fw-config 0 950 1000
```

三个参数依次为最大负 Id 幅值 mA、电压利用率目标千分比、负 Id 目标变化率上限 mA/s。允许范围分别为 0～2000、700～990、100～10000，支持运行中修改。最大值 0 平滑关闭弱磁，配置在停机后保留，复位恢复 1000、950、1000。积分目标向零释放的变化率上限为配置值的两倍。

Iq 预算采用 `sqrt(Imax² − Id_reserved²)`，同时约束速度 PI 输出和最终 Iq 参考。正 Id 启动阶段按完整启动励磁预留 q 轴预算。负 Id 阶段在快环中每 4 ms 预留下一段完整目标电流，释放时保留当前较大负 Id 的预算，保证整个斜坡中的电流矢量约束。预算使用现有平方根表的保守下界，误差上界约为 0.2% 加一个计数。无感 q 轴电压预算使用同样的保守换算，电流与电压矢量均保持在限幅内。弱磁电压环与速度 PI 均为 125 Hz，两者相隔 4 ms 更新，预算计算在这两个更新阶段的下一帧执行，避免计算集中到同一 200 us 帧。`limits 2000 6928` 对应 2 A 总电流矢量和 6928 mV 电压矢量上限。

新增离线回归用解析连续 R/L 电机方程生成电压与电流，避免复用观测器自身的离散公式。覆盖 ±300、±400、±450 rad/s，最大负 Id 1200 mA。1000 rad/s 的数值用例对应每电周约 4.49 个采样，独立检查其连续模型估角误差小于 8°。电流、斜坡、运行时关闭和低速释放另有真实 ARM 控制代码回归。

## 单位与配置

输入电压单位为 mV，电流单位为 mA。电压对应当前采样电流产生前的输出。`Smo_Angle()` 一电周为 16384，`Smo_ElectricalSpeedQ8()` 为每次更新的电角度增量 Q8，采样率变化时数值同步换算。反转的反电动势相位差半周，`Smo_Seed()` 给出启动角度、方向和速度。跨零反转在低速区完成交接。

电感 1000 uH 是待测初值，电阻沿用工程的 3700 mΩ。停止时可以修改参数，随后重新使能。

```powershell
uv run --script tools/host/foc.py smo-config takeover-mv 400
uv run --script tools/host/foc.py smo-config fallback-mv 280
uv run --script tools/host/foc.py smo-config qualify-ms 100
uv run --script tools/host/foc.py smo-config resistance-mohm 3700
uv run --script tools/host/foc.py smo-config inductance-uh 1000
```

## 验证

`uv run --script tools/debug.py verify` 构建独立的 `smo_validation.elf`，在 Unicorn Cortex-M0 上执行实际 ARM 代码，覆盖 50 us、200 us、1 ms、1.6 ms 采样、正反转、反电动势消失和复位。200 us 模型覆盖 ±30、±150、±300、±600、±1000 rad/s，另有 1.6 ms、±160 rad/s 用例检查原有内部速度限幅的回归。600 和 1000 rad/s 用例将反电动势设为 5700 mV，检查降低磁链后的高速观测采样与数值范围。12 V 下的可达速度由实机弱磁结果确认。产物在 `firmware/build/Debug/` 和 `firmware/build/Release/`。

应用入口回放使用理想电流与观测输入，执行真实 `main`、命令解析、Motion 和 Sensorless 代码，覆盖 +60 rad/s 运行中下发 −30 rad/s、SMO 减速、快慢采样率切换、HFI 过零、反向 SMO 接管和停机。ADC 寄存器模型单独检查 5 kHz 均值帧、500 Hz 诊断和频率切换时的电压衔接。对应实机回归记录如下。

```powershell
uv run --script tools/debug.py trace --speed 15 --seconds 3 --divider 5 --frequency 8000000
uv run --script tools/debug.py trace --mode hfi --speed 15 --seconds 2 --divider 5 --frequency 8000000
```

trace 记录 SMO 角度、速度、滤波反电动势、PLL 平均误差、有效状态和就绪状态，以及观测器输入的平均 αβ 电压和电流。报告给出相对编码器的平均角度误差、标准差、95% 绝对误差及就绪比例。`--smo off` 用于计算开销对照。判定时同时检查 `missed_samples_delta`、`hfi_missed_frames_total` 和 `hfi_processed_frames_hz`。HFI 模式下 trace 取点时读取编码器，SMO 的平均电流对应较早的解调帧，逐条角差仍包含平均窗口与处理时延。`--require-smo` 要求采集末尾至少连续 1 秒保持 SMO 控制。

## 2026-11-09 PA3 流程与低速交接修复

60 rad/s 的问题在母线参数化之前的固件上也能复现。低速反电动势较小时，启动正 Id 尚在而过早切换采样率，会导致 SMO 反复回退。当前低速启动先完成正 Id 退出再进快环，达到 100 rad/s 的启动仍允许提前切换，保留高速加速能力。HFI 模式的电流及 q 轴电压预算采用复用现有查表的保守平方根下界，避免该预算的除法开销，同时保持电流、电压矢量限幅。

PA3 软件流程已加入，配置见 `firmware/BSP/Inc/bus_sense.h`。当前真实 ADC 开关为 0，保留 GPIO 按键，采样源固定返回 12 V。启用后第三通道采集 ADC CH3，前台做分压换算、滤波与 KEY 判定。上、下分压电阻暂设 100 kΩ／10 kΩ，按键近零连续两次触发，按下期间保留上次母线值。命令 `bus-voltage 0` 选择占位／ADC 源，非零值选择人工覆盖。

修复后中间固件完成 ±60 与 ±400 rad/s 两个方向的交接，四次控制、诊断、编码器和 RTT 计数均无新增丢失。一次 −60 → +60 rad/s 在控制仍正常时记录了诊断超时，原因是 500 Hz 诊断仍沿用普通 1 kHz 模式的 4 ms 阈值。最终改为四个实际诊断周期，普通模式 4 ms、无感模式 8 ms，真正超时仍上报告警，控制帧由独立超时监视处理。
