# CW32L010 驱动板硬件接口

以下是从固件反推的 MCU 信号和参数。连接器针脚、芯片封装脚号、板上网络名称和电气规格需按实物板版本核对。

## 引脚表

| MCU 引脚 | MCU 外设 | 固件用途 |
| --- | --- | --- |
| PB0 | ATIM CH1 | DRV8313 三相 PWM 的 A 相指令 |
| PB2 | ATIM CH2 | DRV8313 三相 PWM 的 B 相指令 |
| PA0 | ATIM CH4 | DRV8313 三相 PWM 的 C 相指令 |
| PB1 | 推挽输出 | DRV_EN。高电平使能，初始化时置低 |
| PB4 | ADC CH11，序列 0 | B 相电流采样 |
| PB5 | ADC CH12，序列 1 | C 相电流采样 |
| PA5 | I2C1 SDA | MT6701 数据线，开漏 |
| PA6 | I2C1 SCL | MT6701 时钟线，开漏 |
| PA3 | GPIO 输入，内部上拉，双边沿中断 | 低电平请求停机 |
| PA4 | GTIM1 CH3 | 状态 LED 的 PWM 输出，配置为约 1 kHz |
| PA7、PA8 | SWD | 烧录、调试和 RTT |

引脚初始化由 BSP 各驱动负责。PWM 复用及相序见 [DRV8313 驱动](../../firmware/BSP/Src/drv8313.c)。具体 DRV8313 输入脚与电机端子相序需用原理图核对。

## 电机驱动与电流采样

- 固件使用 48 MHz 时钟，ATIM 分频为 1，重装值为 1200，使用中心对齐 PWM，名义频率约 20 kHz。三路为 PWM2、非反相输出。
- FOC 参数为 12 V 母线、7 对极、编码器方向系数 −1。实机扫场时电角度增加两圈，MT6701 原始机械角度下降约 1.76 rad。固件按相序定义角度正方向。12 V 是控制算法的配置值，供电范围和电机额定参数需查板卡资料。
- 电流换算采用 12 位 ADC、3.3 V 参考、10 mΩ 分流电阻和 50 V/V 放大倍数。驱动关闭时采 100 次，计算两相 ADC 零点。
- ATIM CH5 的内部参考信号直接接到 TRGO2，每个 PWM 周期触发一次 ADC，固件每 20 次序列取一组控制样本。A 相按 `Ia = -(Ib + Ic)` 计算。放大器型号后缀、实际分流阻值和电流正方向需查原理图。
- 当前电机的 q 轴电压前馈采用实测估算值，等效电阻为 3.7 Ω。电流模式另外使用 19 mV/(rad/s) 的反电动势系数。速度、位置和轨迹模式根据相邻两次 5 ms 速度环更新之间的测速变化增加阻尼。速度参考的绝对值低于 10 rad/s 时使用全阻尼，10 至 20 rad/s 之间线性减弱，达到 20 rad/s 后停用该补偿。 [控制实现](../../firmware/Control/Src/motion.c)

参数和电流换算见[应用入口](../../firmware/App/Src/main.c)，采样顺序见 [ADC 驱动](../../firmware/BSP/Src/current_adc.c)。

## MT6701 编码器

I2C1 配置为 1 MHz，7 位从地址为 `0x06`。固件从寄存器 `0x03` 连读两个字节，解码为 14 位机械角度，范围 0–16383。总线空闲时，先清中断标志 SI 再发出首个 START，避免清掉新产生的 START 事件。板上 I2C 上拉的位置和阻值需查原理图。 [MT6701 驱动](../../firmware/BSP/Src/mt6701.c)

快 SMO 下每 2 ms 发起一次非阻塞诊断读取，前台在总线状态就绪时逐步推进事务，期间继续更新无感控制。连续无感转动的位置累计使用 32 位 mrad 计数，保留有符号回绕，避免诊断位置在 ±2000 rad 提前饱和。

## SWD 与复位

pyOCD 使用设备包中的 `CW32L010F8` 目标。PA7、PA8 在固件运行期间用于 SWD。烧录和 GDB 服务配置为复位下连接，需核对板上 SWDIO、SWCLK、NRST、参考电压和 GND 的实际引出。

连接器针序、SWDIO/SWCLK 在 PA7/PA8 上的具体对应关系、DRV8313 的故障/睡眠/复位信号接法，以及电源保护和地线分区仍需结合原理图核实。

## SWD 与 RTT

RTT 通过 SWD 访问 MCU RAM。上行通道 0 发送状态，下行通道 0 接收命令，缓冲区分别为 128 和 32 字节。固件约每 40 ms 发送一次状态，接收命令后也尝试立即回复。主机可按 `<HBB6BH9i3I` 解包 60 字节小端帧。上行空间不足时丢弃整帧。

| 字节偏移 | 类型 | 字段 |
| --- | --- | --- |
| 0 | uint16 | 帧标识 `0x4F46`，线上字节为 `46 4F` |
| 2 | uint8 | 版本 `2` |
| 3 | uint8 | 帧长度 `60` |
| 4–9 | 6 × uint8 | 模式、状态、诊断事件、最后一条命令的 ASCII 码、命令结果、保留 |
| 10 | uint16 | 命令应答序号，每处理一条命令加一 |
| 12–44 | 9 × int32 | 目标、机械角度、速度、Id、Iq、Iq 目标、Vd、Vq、轨迹位置或棘轮齿心 |
| 48–56 | 3 × uint32 | 累计丢拍、累计编码器读错误、最近观测到的采样间隔 µs |

目标随模式分别使用 mV、mA、mrad/s、mrad 或每圈齿数。其余量按字段分别使用 mrad、mrad/s、mA 和 mV。模式依次为电压、电流、速度、位置、力位、轨迹、双向棘轮、HFI，编号 0–7。状态依次为未对齐、零点校准、对齐、待使能、运行、脉冲测量、HFI 锁定，编号 0–6。HFI 模式的目标和速度字段以 mrad/s 表示，速度来自 HFI 估算，轨迹位置字段存放估算电角度（mrad），机械位置字段仍来自 MT6701。HFI 的 dq 电流和电压以同步旋转场为参考。事件 6 表示 HFI 丢锁或注入采样超时。

下行命令格式为 `@命令,参数...;`，参数为有符号十进制整数。常用命令为 `Q` 查询，`C` 校准，`E` 使能，`X` 停机，`R` 清诊断，以及 `V/I/S/P/Z/T/H/Y` 选择模式。例如 `@P,1571;` 将位置目标设为 1571 mrad，`@Y,1500;` 将 HFI 速度目标设为 1500 mrad/s。`@F,注入电压,Id目标,峰值电流;` 实时设置 HFI 注入 mV、Id mA 和 ADC 瞬时阈值 mA。`@L,Iq上限,电压上限;` 实时设置全局电流 mA 和电压 mV 限值。F/L 仅在待机状态修改，参数保存在 RAM，复位恢复默认。 [命令处理](../../firmware/App/Src/main.c) · [CLI 使用](../../README.md#rtt-cli)

`@H,齿数,峰值电流,附加阻尼;` 选择双向棘轮，参数分别为每圈 1–120 齿、1–500 mA、0–100 mA/(rad/s)。高于 250 mA 的力度在棘轮测速绝对值不超过 0.6 rad/s 时逐步启用，约 20 ms 达到设定上限。实际电流还受 3 V 输出限幅和电机工况约束。固件会按齿数和当前上限增加基础阻尼，快速回到齿心时减弱拉力。

上行通道 1 用 512 字节缓冲区记录高速数据。`@D,帧数,分频;` 启动限次记录，`@D,0;` 结束。每帧按 `<IIi4H5hH` 解包，依次为 ADC 样本序号、固件采样时间 µs、估算速度 mrad/s、MT6701 原始角度、电角度、两路 ADC、Id、Iq、Iq 目标、Vd、Vq、记录序号。角度为 14 位计数，65535 表示无效。电流和电压以 mA 和 mV 表示。 [高速采集命令](../debugging.md#实机取证与限时测试)

`@J,幅值,周期数,重复数;` 在待使能且转子静止时启动脉冲实验。幅值为 0–500 mV，周期数为 1–4，重复数为 1–64。上行通道 1 返回四个 96 字节小端包 `<HBB4HI10i10I`。字段依次为标记 `0x4A46`、矢量编号、周期数、故障码、起止电角度、最大机械位移 mrad、有效重复次数、五组 B/C 差分 ADC 和及平方和。只使用前 `周期数 + 1` 组。实验与高速跟踪分时使用通道 1。 [测量流程](../debugging.md#实机取证与限时测试)
